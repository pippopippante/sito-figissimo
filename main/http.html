http

protocollo che permette di trasferire risorse web tra client e server

  • client → macchina su cui risiede il browser
  • browser → richiede il servizio
  • server → macchina su cui risiede il sito web

Utilizza un meccanismo richiesta risposta

il protocollo http opera in 4 fasi:

  1. connessione: viene instaurata la connessione TCP(orientato alla connessione protocollo di rete) tra C/S
  2. risposta: il server invia la pagina html al client
  3. disconnessione: il client una volta ricevuta la pagina, chiude la connessione TCP(e’ stato modificato, si mantiene aperta la connessione per ulteriori richieste da parte del client)

Tipologie HTTP

  • HTTP 1.0: ogni risorsa viene richiesta all’interno di una connessione
  • HTTP 1.1: su una stessa connessione TCP il client puo’ inviare piu’ richieste, ma una alla volta → permanentemente non incatenata
  • HTTP 1.1 con pipeling: il client puo’ inviare piu’ richieste contemporaneamente nella stessa connessione senza aspettare le risposte del server → permanentemente incatenata
