DATABASE

Un database è un sistema organizzato per archiviare e gestire dati, rendendoli facilmente accessibili, aggiornabili e utilizzabili

Caratteristiche principali di un database:

  • Dati organizzati in tabelle: I dati sono organizzati in righe e colonne, simili a un foglio di calcolo
  • DBMS: Software che gestisce il database
  • Interfaccia per l'accesso: Consente agli utenti o alle applicazioni di interagire con i dati attraverso query

Tipi di database:

  • Database relazionali (RDBMS): Basati su tabelle relazionate tra loro tramite chiavi
  • Database non relazionali (NoSQL): Organizzati in modo diverso da tabelle, come documenti, grafi o chiavi-valori
  • Database orientati agli oggetti: Architettura basata su oggetti piuttosto che su tabelle

SQL

(structured query language)

è un linguaggio di programmazzione che permette di interrogare un database

dei comandi base sono:

  • select: chiede al database cosa cercare
  • from: seleziona la cartella in cui cercare
  • were: aggiunge delle condizioni alla ricerca
  • like: seleziona la prima lettera
  • order by: ordina alfabetico/maggiore minore aggiungendo desk si inverte

sql è diviso in 2 parti ddl che si occupa di creare e distruggere cartelle
