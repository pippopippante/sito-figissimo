Integrali

otto ricette. per ognuna: come si chiama, quando si usa, come si fa.

vale per tutte: se l'integrale è indefinito, alla fine ci va + c.

Da dove parti

  1. è già una di base? hai finito
  2. dentro c'è già la derivata di un pezzo? → composte
  3. c'è una parte scomoda da rinominare? → sostituzione
  4. è un prodotto di due cose di tipo diverso? → per parti
  5. è un polinomio fratto un polinomio? → fratte
01

Base

quandosono i mattoni: il punto in cui ogni altra ricetta deve farti arrivare. Se sei qui, hai finito.

formule

potenza ∫xn dx  =  xn+1n+1

n ≠ −1  ·  se n = −1 è il logaritmo qui sotto

reciproco ∫ 1x dx  =  ln |x|

il valore assoluto ci va sempre

esponenziale ∫ex dx  =  ex    ·    ∫e−x dx  =  −e−x
base a ∫ax dx  =  axln a
goniometriche sen  →  cos  →  −sen sen  ←  −cos  ←  −sen ∫sen x = −cos x   ·   ∫cos x = sen x

→ derivi  ·  ← integri

quelle scordate ∫ 1cos2x dx = tan x ∫tan x dx = −ln|cos x|
02

Integrali fast

quandoli devi riconoscere a occhio, senza calcolare niente. Sono le risposte in cui finiscono quasi tutti gli esercizi.

formule

arctan ∫ 11+x2 dx  =  arctan x
arcsin ∫ 11−x2 dx  =  arcsin x
arctan con y ∫ 1x2+y2 dx  =  1y arctan xy

è quello che ti serve nelle fratte con Δ < 0

regola del 1/a

se dentro c'è ax+b, integri normale e poi dividi per a.

es.

∫eax dx = 1aeax   ·   ∫sen(ax) dx = −1acos(ax)   ·   ∫ 1ax+b dx = 1aln|ax+b|

vale solo se dentro è di primo grado: con x² non funziona, lì serve la sostituzione

x1,2 −b ± b2−4ac 2a

serve per scomporre i denominatori

03

Composte

quandoaccanto a f(x) trovi già la sua derivata f ′(x). È la sostituzione fatta a mente: se la vedi, non serve scrivere niente.

procedimento

  1. riconosci f(x) e la sua derivata dentro l'integrale
  2. integri solo la funzione di fuori e lasci f(x) dov'è
  3. se manca una costante la metti dentro e la compensi fuori dall'integrale

formule

potenza ∫[f]a · f ′ dx  =  [f]a+1 a+1

a ≠ −1

logaritmo ∫ f ′f dx  =  ln |f|

valore assoluto, non parentesi quadre

tutte le altre ∫f ′ ef = ef   ·   ∫f ′ sen f = −cos f   ·   ∫ f ′1+f2 = arctan f

esempio

∫2x(x2+1)3 dx = (x2+1)44 + c ∫ 2xx2+1 dx = ln(x2+1) + c
04

Sostituzione

quandoc'è una parte scomoda che puoi rinominare, e non riesci a vedere la composta a occhio.

procedimento

  1. individua la parte scomoda: g(x) = t
  2. dx = dtg ′(x)
  3. sostituisci i pezzi: ∫g(x) dx  →  ∫t dtg ′(x)
    • per tutte le x: deve essere tutto t
  4. risolvi e torni a x

esempio

∫x x2+1 dx t = x2+1  →  dt = 2x dx  →  x dx = dt2 12 ∫t dt = 13 t3/2 = 13 (x2+1)3/2 + c

se l'integrale è definito: o cambi anche gli estremi passando a t, o torni alla x prima di sostituirli. Non mischiare le due cose.

05

Per parti

f(x) · g(x)

quandoè un prodotto di due funzioni di tipo diverso (un polinomio per un'esponenziale, un logaritmo per una potenza…) e non c'è nessuna derivata già pronta dentro.

la formula

∫f · g dx  =  f · G  −  ∫f ′ · G dx     dove G = ∫g

l'integrale che ti resta deve essere più facile di quello di partenza: se peggiora, hai scelto al contrario

procedimento

  1. decidi chi è f e chi è g
    • f verrà derivato
    • g verrà integrato
  2. scegli il f con questo ordine — il primo che trovi lo derivi
      1. ln(x)
      2. arctan / arcsin
      3. x2 …
      4. sen(x), cos(x)
      5. ex
  3. applichi la formula e risolvi l'integrale che resta

esempio

∫x ln x dx   →   f = ln x  ·  G = x22 = x22 ln x − x24 + c

il caso che torna indietro

con ex · sen x (o cos) applichi per parti due volte e ti ritrovi l'integrale di partenza. Chiamalo I, portalo a sinistra e risolvi come un'equazione.

I = … − I  →  2I = …  →  I = …2
06

Fratte

f(x)g(x)

quandoè un polinomio diviso un polinomio. Non si integra così com'è: va spezzato finché non diventa una somma di fratte base.

procedimento

  1. sopra c'è la derivata di sotto? → è solo un logaritmo, hai finito
  2. è già una fratta base? → vedi la tabella qui sotto
  3. grado f ≥ grado g → fai la divisione tra polinomi
    • resta quoziente + restog, e il resto ora ha grado più basso
  4. grado f < grado g → vai alle fratte algebriche

le fratte base — dove devi arrivare

primo grado ∫ 1x−x0 dx = ln|x−x0|
con il coefficiente ∫ 1ax+b dx = 1a ln|ax+b|
al quadrato ∫ 1(x−x0)2 dx = − 1x−x0
alla n ∫ 1(x−x0)n dx = 1 (1−n)(x−x0)n−1

n ≠ 1  ·  è la potenza normale con esponente −n

derivata sopra ∫ g ′(x)g(x) dx = ln|g(x)|
somma di quadrati ∫ 1x2+y2 dx = 1y arctan xy

non si scompone: qui non ci sono radici reali

esempio

∫ 2x+3x2+3x+1 dx = ln|x2+3x+1| + c

sopra c'è esattamente la derivata di sotto: passo 1, niente scomposizione

07

Fratte algebriche

g(x) di grado 2

quandosei arrivato a una fratta con il numeratore di grado più basso del denominatore, e il denominatore è di grado 2. Serve a spezzarla nelle fratte base.

procedimento

  1. calcoli il Δ del denominatore
  2. spezzi la frazione secondo il caso qui sotto
  3. trovi A e B sostituendo dei valori di x
  4. integri ogni pezzo con le fratte base

i tre casi

Δ > 0 — due radici, due logaritmi
f(x)g(x)  =  Ax−x1 + Bx−x2  →  f(x) = A(x−x2) + B(x−x1)
  1. metti x = x1: il pezzo con B si annulla → esce A
  2. metti x = x2 → esce B
=  A ln|x−x1| + B ln|x−x2| + c
Δ = 0 — radice doppia
f(x)(x−x0)2  =  Ax−x0 + B(x−x0)2  →  f(x) = A(x−x0) + B =  A ln|x−x0| − Bx−x0 + c
Δ < 0 — non si scompone: log + arctan
  1. spezza il numeratore in derivata del denominatore + costante: f(x) = A · g ′(x) + B
  2. il pezzo con A è un logaritmo: A ln|g(x)|
  3. sul pezzo con B completa il quadrato: g(x) = (x+k)2 + y2
∫ dx(x+k)2+y2  =  1y arctan x+ky =  A ln|g(x)| + By arctan x+ky + c

se il denominatore è di grado 3

p(x)(x−x0)(x2+bx+c)  =  Ax−x0 + Bx+Cx2+bx+c p(x) = A(x2+bx+c) + (Bx+C)(x−x0)

sul pezzo di grado 1 sopra il quadratico ricadi nel caso Δ < 0

08

Impropri

quandoun estremo è ±∞, oppure la funzione esplode in un punto dell'intervallo. La domanda non è "quanto fa" ma converge o diverge.

procedimento

  1. trova dov'è il problema: l'estremo infinito, o il punto in cui la funzione va a ∞
  2. sostituisci quell'estremo con una lettera e mettici davanti un limite
  3. risolvi l'integrale normale, con una delle ricette di sopra
  4. fai il limite: viene un numero → converge, viene ∞ → diverge

se i problemi sono due, spezzi in due integrali e devono convergere tutti e due

come si scrive

∫+∞a f dx  =  limb→+∞ ∫ba f dx [F(x)]ba  =  F(b) − F(a)

criterio 1/xα — per rispondere senza calcolare

problema all'∞ ∫+∞a 1xα dx    converge se  α > 1
problema in 0 ∫a0 1xα dx    converge se  α < 1

sono al contrario  ·  con α = 1 diverge da tutte e due le parti

niente che corrisponde.
